# Skill: Phase Validation

Cette skill permet de valider le passage d'une phase du projet à une autre de manière rigoureuse.

## Responsabilités
1. **Contrôle des critères :** Vérifier point par point si les livrables d'une phase ont été créés et complétés.
2. **Production de Checklist :** Rédiger un fichier de checklist de validation de phase temporaire pour recueillir la signature de l'utilisateur.
3. **Signalement des manques :** Flaguer les éléments manquants, vides, ou au statut `À rédiger` pour transparence.
4. **Preuve formelle :** Ne jamais valider une phase sans s'être assuré que les critères d'acceptation physiques sont remplis.
