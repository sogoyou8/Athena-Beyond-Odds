# Contraintes Connues (Known Constraints)

- **Langue :** Toute documentation humaine doit être en français.
- **Nomenclature :** Les noms techniques (fichiers, dossiers, Git, code futur) doivent être en anglais.
- **Périmètre Sportif Initial :** Football uniquement.
- **Transparence :** Aucune promesse de gains ou de résultats sportifs garantis.
- **Pas de Code Applicatif :** Ne créer aucun code d'application ou installer des paquets/dépendances applicatifs pendant cette phase de fondation.
- **Pas de Stack Définitive :** Ne pas figer de choix de stack technique définitive avant le lancement officiel de la phase d'architecture.
