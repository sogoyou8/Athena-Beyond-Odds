# User Journeys

> **Version :** 1.0  
> **Statut :** Brouillon

---

## 1. Première découverte

```text
Landing Page
→ Proposition de valeur
→ Exemple de Match Center
→ Création de compte
→ Onboarding
→ Dashboard
```

Critères :

- compréhension en moins de deux minutes ;
- inscription simple ;
- aucun paiement obligatoire ;
- accès rapide à une première valeur.

---

## 2. Onboarding

Étapes :

1. langue ;
2. fuseau horaire ;
3. niveau d’expertise ;
4. sports ;
5. compétitions ;
6. équipes ;
7. types d’alertes ;
8. consentements ;
9. premier Dashboard.

---

## 3. Comprendre un match

```text
Recherche ou Dashboard
→ Match Center
→ Résumé
→ Facteurs clés
→ Probabilités
→ Statistiques
→ Explication Athena
→ Favori ou alerte
```

---

## 4. Suivre un live

```text
Notification
→ Live Center
→ Timeline
→ Statistiques live
→ Évolution des probabilités
→ Fin du match
→ Résumé après-match
```

---

## 5. Comparer deux équipes

```text
Compare
→ Sélection A
→ Sélection B
→ Période
→ Métriques
→ Visualisation
→ Résumé
→ Export éventuel
```

---

## 6. Créer une alerte

```text
Match ou entité
→ Créer une alerte
→ Choisir le déclencheur
→ Choisir le canal
→ Choisir la fréquence
→ Confirmer
```

---

## 7. Passer Premium

```text
Fonction verrouillée
→ Explication de la valeur
→ Comparaison des offres
→ Paiement
→ Confirmation
→ Déverrouillage immédiat
```

Aucun blocage artificiel.

---

## 8. Signaler une erreur

```text
Contenu
→ Signaler
→ Catégorie
→ Commentaire
→ Confirmation
→ Suivi
```

---

## 9. Résilier

```text
Abonnement
→ Gérer
→ Résilier
→ Conséquences claires
→ Confirmation
→ Accès jusqu’à échéance
```

Sans dark pattern.

---

## 10. Critères communs

Chaque parcours doit :

- afficher une progression ;
- préserver le contexte ;
- gérer les erreurs ;
- rester accessible ;
- mesurer les abandons ;
- confirmer les actions sensibles.
