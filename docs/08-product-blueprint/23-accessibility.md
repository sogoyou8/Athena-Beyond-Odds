# Accessibility

> **Version :** 1.0  
> **Statut :** Brouillon

---

## 1. Cible

WCAG 2.2 AA pour les parcours essentiels.

---

## 2. Exigences

- clavier ;
- focus visible ;
- ordre logique ;
- labels ;
- alternatives ;
- contraste ;
- zoom ;
- reflow ;
- réduction des mouvements ;
- messages d’erreur associés ;
- tableaux accessibles.

---

## 3. Graphiques

Chaque graphique doit proposer :

- titre ;
- description ;
- légende ;
- données tabulaires ;
- valeurs accessibles ;
- absence de dépendance exclusive à la couleur.

---

## 4. Live

Les mises à jour ne doivent pas perturber le lecteur d’écran.

Utiliser des annonces contrôlées.

---

## 5. Tests

- automatisés ;
- clavier ;
- lecteur d’écran ;
- contraste ;
- zoom ;
- utilisateurs réels.

---
