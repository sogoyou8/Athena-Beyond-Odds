# Offline Strategy

> **Version :** 1.0  
> **Statut :** Brouillon

---

## 1. Objectif

Maintenir une expérience utile en connexion faible ou absente.

---

## 2. Données cacheables

- favoris ;
- derniers Match Centers ;
- calendrier proche ;
- préférences ;
- rapports téléchargés ;
- contenu explicatif statique.

---

## 3. Données non garanties hors ligne

- live ;
- cotes ;
- nouvelles compositions ;
- notifications temps réel ;
- analyses recalculées.

---

## 4. Indicateurs

Afficher clairement :

- hors ligne ;
- dernière synchronisation ;
- contenu potentiellement obsolète ;
- actions en attente.

---

## 5. Synchronisation

- file locale ;
- idempotence ;
- résolution de conflit ;
- reprise ;
- expiration.
