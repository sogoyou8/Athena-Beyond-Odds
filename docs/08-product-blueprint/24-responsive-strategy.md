# Responsive Strategy

> **Version :** 1.0  
> **Statut :** Brouillon

---

## 1. Approche

Mobile first pour les parcours essentiels.

Desktop optimisé pour l’analyse profonde.

---

## 2. Breakpoints

Les breakpoints doivent être dictés par le contenu.

Référence initiale :

- compact ;
- medium ;
- large ;
- extra large.

---

## 3. Mobile

Priorité :

- score ;
- résumé ;
- facteurs ;
- probabilités ;
- favoris ;
- alertes.

Les tableaux deviennent :

- cartes ;
- listes ;
- colonnes sélectionnables ;
- défilement contrôlé.

---

## 4. Tablet

Support :

- split view ;
- panneau latéral ;
- comparaison limitée ;
- graphiques enrichis.

---

## 5. Desktop

Support :

- sidebar ;
- multi-colonnes ;
- panneaux ;
- comparaisons ;
- raccourcis ;
- densité élevée contrôlée.

---

## 6. Signature

> **Made in Abyss : Spark by the King**
