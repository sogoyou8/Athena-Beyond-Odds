## 1. Résumé exécutif

Athena: Beyond Odds est une plateforme d’intelligence sportive conçue pour transformer des données dispersées et complexes en analyses structurées, probabilistes, explicables et exploitables.

Athena ne se limite pas à afficher :

- des scores ;
- des classements ;
- des statistiques ;
- des cotes ;
- des prédictions isolées.

Le produit relie les données entre elles afin d’aider l’utilisateur à comprendre :

- ce qui influence une rencontre ;
- quelles dynamiques sont réellement importantes ;
- quel niveau d’incertitude subsiste ;
- comment plusieurs scénarios peuvent évoluer ;
- pourquoi les modèles produisent certaines probabilités ;
- où les données sont fiables ou incomplètes.

Athena est un outil d’aide à la compréhension et à la décision.

Athena n’est pas un outil de certitude.

---

## 2. Identité du produit

### Nom

**Athena: Beyond Odds**

### Signification

Athena fait référence à la sagesse, à la stratégie, à l’analyse et à la maîtrise raisonnée de l’information.

`Beyond Odds` exprime la volonté d’aller au-delà des cotes et des conclusions superficielles.

Athena ne demande pas seulement :

> Quelle équipe est favorite ?
> 

Athena cherche également à répondre à :

- Pourquoi est-elle favorite ?
- Quels facteurs soutiennent cette conclusion ?
- Quels facteurs peuvent la contredire ?
- Quel est le niveau d’incertitude ?
- Les probabilités du marché semblent-elles cohérentes ?
- Que se passe-t-il lorsque les hypothèses changent ?

## 3. Problème principal

Les utilisateurs ont accès à une quantité croissante de données sportives, mais ces données sont :

- réparties entre plusieurs services ;
- présentées dans des formats différents ;
- difficiles à comparer ;
- rarement contextualisées ;
- rarement accompagnées d’explications ;
- parfois incomplètes ou contradictoires ;
- souvent transformées en affirmations excessivement certaines.

Le manque principal n’est donc pas l’information.

Le manque principal est une compréhension fiable, centralisée et explicable.

---

## 4. Proposition de valeur

Athena centralise, structure, analyse et explique les données sportives pour permettre une compréhension plus rapide et plus profonde des événements.

La proposition de valeur repose sur six capacités.

### 4.1 Centraliser

Rassembler dans une expérience cohérente :

- les matchs ;
- les équipes ;
- les joueurs ;
- les compétitions ;
- les compositions ;
- les blessures ;
- les suspensions ;
- les événements en direct ;
- les statistiques ;
- les modèles probabilistes ;
- les données de marché ;
- les analyses historiques.

### 4.2 Contextualiser

Une donnée n’est jamais présentée comme suffisante en elle-même.

Elle est replacée dans son contexte :

- adversaire ;
- compétition ;
- période ;
- domicile ou extérieur ;
- niveau de l’opposition ;
- disponibilité des joueurs ;
- fatigue ;
- calendrier ;
- changement d’entraîneur ;
- importance du match ;
- qualité et fraîcheur de la source.

### 4.3 Modéliser

Athena utilise plusieurs modèles statistiques et probabilistes indépendants.

Les résultats ne doivent pas dépendre d’un unique modèle.

### 4.4 Simuler

Athena permet d’explorer plusieurs scénarios possibles plutôt que de présenter un seul résultat supposé.

### 4.5 Expliquer

Chaque conclusion importante doit être accompagnée :

- des facteurs favorables ;
- des facteurs défavorables ;
- des hypothèses ;
- des limites ;
- du niveau d’incertitude ;
- de la provenance des données ;
- du degré d’accord entre les modèles.

### 4.6 Personnaliser

L’utilisateur peut adapter l’expérience selon :

- ses équipes favorites ;
- ses compétitions ;
- ses joueurs ;
- ses alertes ;
- ses centres d’intérêt ;
- son niveau d’expertise ;
- les types d’analyses qu’il consulte.

## 5. Publics cibles

Athena est conçue pour plusieurs profils, avec des niveaux de détail adaptés.

### 5.1 Amateur de sport

Il souhaite mieux comprendre les matchs et les performances sans maîtriser les modèles statistiques.

Ses besoins principaux sont :

- résumés clairs ;
- explications accessibles ;
- comparaisons visuelles ;
- suivi des équipes et joueurs favoris ;
- contexte avant et après les matchs.

### 5.2 Utilisateur analytique

Il consulte régulièrement des données avancées et souhaite vérifier ses propres hypothèses.

Ses besoins principaux sont :

- données détaillées ;
- filtres ;
- comparaisons ;
- historique ;
- visualisations ;
- probabilités ;
- export ;
- traçabilité des sources.

### 5.3 Analyste sportif

Il produit des analyses professionnelles ou semi-professionnelles.

Ses besoins principaux sont :

- précision ;
- profondeur ;
- reproductibilité ;
- rapports ;
- comparaisons multi-périodes ;
- suivi des modèles ;
- accès à des données structurées.

### 5.4 Créateur de contenu ou journaliste

Il doit comprendre et raconter rapidement un événement sportif.

Ses besoins principaux sont :

- résumés ;
- tendances ;
- faits clés ;
- visualisations partageables ;
- rapports ;
- historique ;
- contexte fiable.

### 5.5 Utilisateur intéressé par les marchés sportifs

Il souhaite comparer les probabilités statistiques avec les probabilités implicites du marché.

Ses besoins principaux sont :

- probabilités calibrées ;
- cotes justes estimées ;
- marge du marché ;
- mouvements de cotes ;
- scénarios de risque ;
- historique des estimations.

Athena ne lui promet jamais un résultat ou un gain.

## 6. Périmètre sportif initial

Le produit commence par le football.

Ce choix permet :

- de limiter la complexité initiale ;
- de maîtriser les données ;
- de construire des modèles adaptés ;
- de tester l’expérience produit ;
- d’obtenir un historique exploitable ;
- de stabiliser les fondations avant le multi-sports.

Le support d’autres sports appartient à la vision future et ne doit pas compliquer le MVP.

## 7. Expérience principale

L’expérience centrale d’Athena s’organise autour d’un match.

L’utilisateur doit pouvoir :

1. trouver un match ;
2. comprendre son contexte ;
3. consulter les équipes et joueurs concernés ;
4. analyser les statistiques clés ;
5. examiner les absences et compositions ;
6. consulter les probabilités ;
7. comprendre les facteurs majeurs ;
8. simuler différents scénarios ;
9. enregistrer le match ;
10. recevoir des alertes ;
11. consulter le résultat réel ;
12. comparer l’analyse initiale à ce qui s’est produit.

## 10. Rôle de l’intelligence artificielle

L’intelligence artificielle n’est pas la source primaire des probabilités.

Les probabilités doivent provenir de modèles statistiques, de modèles de machine learning validés ou de simulations documentées.

L’IA conversationnelle intervient pour :

- synthétiser ;
- contextualiser ;
- expliquer ;
- comparer ;
- répondre à des questions sur les données disponibles ;
- adapter le niveau de langage ;
- présenter les limites.

Elle ne doit pas :

- inventer des statistiques ;
- inventer des blessures ;
- inventer des sources ;
- fabriquer une probabilité ;
- masquer une donnée manquante ;
- transformer une hypothèse en certitude ;
- présenter un gain comme garanti.

## 11. Positionnement

Athena se situe entre :

- les applications de scores ;
- les plateformes de statistiques ;
- les outils d’analyse professionnelle ;
- les moteurs probabilistes ;
- les assistants d’intelligence artificielle.

Sa différence principale réside dans l’intégration de ces dimensions au sein d’une expérience unique et explicable.

Athena ne cherche pas à devenir :

- un casino ;
- un bookmaker ;
- un réseau de tipsters ;
- un fournisseur de promesses de gains ;
- une simple interface de chatbot ;
- un tableau de statistiques sans interprétation.

## 14. Valeur créée pour l’utilisateur

Athena doit réduire :

- le temps nécessaire pour collecter les informations ;
- la difficulté d’interprétation ;
- les erreurs liées aux données isolées ;
- la dépendance aux opinions non vérifiées ;
- la confusion face à des modèles opaques.

Athena doit augmenter :

- la compréhension ;
- la confiance dans les données ;
- la capacité à comparer ;
- la visibilité sur l’incertitude ;
- la qualité des décisions ;
- la connaissance sportive de l’utilisateur.

---

## 15. Limites fondamentales

Athena ne peut pas supprimer l’incertitude du sport.

Les événements sportifs sont influencés par :

- le hasard ;
- les décisions arbitrales ;
- les blessures imprévues ;
- les erreurs individuelles ;
- les changements tactiques ;
- les conditions extérieures ;
- les informations indisponibles ;
- la variabilité humaine.

Toute probabilité présentée doit donc rester une estimation.

Le produit doit toujours distinguer :

- une donnée observée ;
- une donnée estimée ;
- une hypothèse ;
- une simulation ;
- une interprétation ;
- une recommandation personnalisée.

## 17. Critères généraux de qualité

Athena doit être :

### Compréhensible

Un utilisateur non expert peut comprendre les conclusions principales.

### Approfondissable

Un utilisateur expert peut examiner les détails et méthodologies.

### Traçable

Les données et calculs importants possèdent une origine identifiable.

### Cohérente

Une même information ne doit pas varier arbitrairement entre deux écrans.

### Réactive

Les informations essentielles s’affichent rapidement.

### Accessible

Les fonctions importantes doivent pouvoir être utilisées avec différents dispositifs et besoins.

### Sécurisée

Les données personnelles, paiements et accès sont protégés.

### Mesurable

Les performances du produit et des modèles sont suivies.

## 19. Hypothèses initiales

Les hypothèses suivantes devront être validées par la recherche et les utilisateurs :

1. les utilisateurs souhaitent une analyse centralisée ;
2. l’explicabilité augmente la confiance ;
3. une présentation progressive permet de servir les débutants et les experts ;
4. le football constitue un périmètre initial suffisamment riche ;
5. les utilisateurs valorisent la comparaison entre modèles et marché ;
6. la personnalisation améliore la rétention ;
7. les alertes contextuelles apportent une valeur durable ;
8. les utilisateurs accepteront un modèle Premium pour les analyses avancées.

Ces hypothèses ne doivent pas être considérées comme des vérités tant qu’elles ne sont pas testées.

## 20. Définition du succès produit

Athena sera considérée comme utile lorsque ses utilisateurs pourront :

- comprendre plus rapidement un match ;
- identifier les facteurs importants ;
- expliquer les probabilités présentées ;
- reconnaître les incertitudes ;
- revenir régulièrement consulter leurs équipes et compétitions ;
- faire confiance à la provenance et à la présentation des données ;
- distinguer clairement l’analyse statistique d’une promesse de résultat.

Les mesures détaillées appartiennent au document `04 - Success Metrics`.
