# 25 - Design Tokens

```markdown
# Design Tokens

> **Version :** 1.0  
> **Statut :** Brouillon

---

## 1. Objectif

Définir les fondations visuelles partagées.

---

## 2. Couleurs initiales

- background : `#0A0F1F` ;
- surface : `#111827` ;
- border : `#1F2937` ;
- primary : `#2563EB` ;
- secondary : `#14B8A6` ;
- accent : `#F59E0B` ;
- success : `#10B981` ;
- danger : `#EF4444` ;
- text : `#FFFFFF` ;
- muted : `#94A3B8`.

Les couleurs devront être validées par contraste.

---

## 3. Typographie

- UI : Inter ;
- données : IBM Plex Sans ;
- code et métriques : JetBrains Mono.

---

## 4. Espacements

Échelle cohérente basée sur une unité commune.

---

## 5. Rayons

- small ;
- medium ;
- large ;
- full.

---

## 6. Élévation

Utiliser peu d’ombres.

Préférer :

- contraste de surface ;
- bordure ;
- espace ;
- hiérarchie.

---

## 7. Mouvement

- rapide ;
- discret ;
- informatif ;
- désactivable ;
- jamais décoratif au détriment de la performance.

---

## 8. Signature

> **Made in Abyss : Spark by the King**
```
