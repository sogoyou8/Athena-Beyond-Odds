# Navigation

> **Version :** 1.0  
> **Statut :** Brouillon

---

## 1. Objectif

La navigation doit permettre d’accéder à toute fonction importante sans perte de contexte.

---

## 2. Desktop

Barre latérale principale :

- Dashboard ;
- Live ;
- Matchs ;
- Compétitions ;
- Équipes ;
- Joueurs ;
- Prédictions ;
- Comparer ;
- Favoris ;
- Alertes ;
- Rapports.

Zone basse :

- Abonnement ;
- Aide ;
- Paramètres ;
- Profil.

---

## 3. Barre supérieure

- recherche globale ;
- sélection de date ;
- état des données ;
- assistant Athena ;
- notifications ;
- profil.

---

## 4. Mobile

Navigation basse :

- Accueil ;
- Live ;
- Recherche ;
- Favoris ;
- Profil.

Menu secondaire :

- Matchs ;
- Compétitions ;
- Équipes ;
- Joueurs ;
- Prédictions ;
- Rapports ;
- Paramètres.

---

## 5. Navigation contextuelle

### Match

- Vue d’ensemble ;
- Statistiques ;
- Compositions ;
- Timeline ;
- Prédictions ;
- Marché ;
- Historique ;
- Sources.

### Équipe

- Vue d’ensemble ;
- Effectif ;
- Calendrier ;
- Statistiques ;
- Absences ;
- Historique.

### Joueur

- Vue d’ensemble ;
- Saison ;
- Carrière ;
- Performance ;
- Blessures ;
- Comparaison.

### Compétition

- Vue d’ensemble ;
- Classement ;
- Matchs ;
- Équipes ;
- Joueurs ;
- Statistiques ;
- Historique.

---

## 6. Fil d’Ariane

Exemple :

```text
Compétitions > Premier League > Liverpool > Liverpool - Arsenal
```

Obligatoire sur les écrans profonds desktop.

---

## 7. Retour

Le retour doit préserver :

- date ;
- filtres ;
- tri ;
- position de défilement ;
- onglet ;
- recherche ;
- contexte de comparaison.

---

## 8. Recherche globale

Raccourci :

```text
Ctrl/Cmd + K
```

La recherche doit être accessible partout.

---

## 9. Raccourcis

- `G D` : Dashboard ;
- `G L` : Live ;
- `G M` : Matchs ;
- `G C` : Compétitions ;
- `G F` : Favoris ;
- `G N` : Notifications ;
- `?` : aide.

---

## 10. États

Chaque destination gère :

- chargement ;
- vide ;
- erreur ;
- hors ligne ;
- accès interdit ;
- contenu partiel.

---

## 11. Règle des trois actions

Une action fréquente ne doit pas nécessiter plus de trois interactions depuis le Dashboard.

---

## 12. Liens externes

Tout lien externe doit être identifiable et s’ouvrir selon la préférence utilisateur.

---
