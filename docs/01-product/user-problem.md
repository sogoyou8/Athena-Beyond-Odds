# Problème utilisateur

## Contexte

Le sport génère une quantité immense de données.

Résultats, statistiques, compositions, blessures, historique des confrontations, forme récente, calendrier, performances individuelles, conditions de jeu...

Ces informations sont disponibles, mais elles sont dispersées entre de nombreuses plateformes et restent difficiles à interpréter.

La majorité des utilisateurs doivent consulter plusieurs sites avant de pouvoir construire leur propre analyse.

---

# Le problème principal

Les données existent.

La compréhension manque.

Aujourd'hui, les utilisateurs disposent d'informations mais rarement d'explications.

Ils voient des statistiques.

Ils ne savent pas toujours ce qu'elles signifient.

---

# Les difficultés rencontrées

## Trop de sources

Les informations sont réparties entre plusieurs applications et sites spécialisés.

L'utilisateur perd du temps à comparer et à vérifier les données.

---

## Trop de données

Les plateformes affichent parfois des centaines de statistiques.

Il devient difficile d'identifier les informations réellement importantes.

---

## Manque de contexte

Une statistique isolée ne permet pas de comprendre une rencontre.

Chaque donnée doit être replacée dans son contexte :

- forme actuelle ;
- adversaire ;
- style de jeu ;
- historique ;
- importance du match ;
- calendrier.

---

## Analyses superficielles

Beaucoup de plateformes affichent des chiffres.

Peu expliquent réellement les relations entre ces chiffres.

---

## Manque d'aide à la décision

Les utilisateurs doivent eux-mêmes interpréter toutes les informations.

Ils disposent rarement d'un outil capable de synthétiser les données et de mettre en évidence les éléments les plus pertinents.

---

# Les conséquences

Les utilisateurs :

- passent beaucoup de temps à analyser ;
- oublient certaines informations importantes ;
- interprètent parfois mal les statistiques ;
- prennent des décisions avec une vision incomplète.

---

# Notre conviction

Les données seules ne créent pas de valeur.

La valeur apparaît lorsque les données deviennent :

- compréhensibles ;
- contextualisées ;
- explicables ;
- exploitables.

---

# Ce que nous voulons résoudre

Athena a pour objectif de transformer une grande quantité de données sportives en une analyse claire, structurée et compréhensible.

L'utilisateur ne doit plus chercher l'information.

Il doit comprendre rapidement les facteurs importants qui influencent une rencontre.

---

# Résumé

Le problème n'est pas le manque de données.

Le véritable problème est le manque de compréhension.
